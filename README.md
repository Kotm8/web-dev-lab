# Лабораторная работа №2
## Тема: Проектирование и реализация RESTful API

### Цель работы
1.  Изучить архитектурный стиль REST и принципы построения веб-сервисов.
2.  Освоить работу с HTTP-методами (GET, POST, PUT, PATCH, DELETE) и кодами состояний.
3.  Получить практические навыки подключения реляционной СУБД (PostgreSQL) к веб-приложению.
4.  Освоить механизм миграций базы данных для управления схемой данных.
5.  Изучить основы работы с ORM (Object-Relational Mapping) для абстракции работы с данными.
6.  Реализовать механизм мягкого удаления (Soft Delete) данных.
7.  Реализовать пагинацию для списковых методов API.
8.  Закрепить навыки контейнеризации приложений с помощью Docker и оркестрации сервисов через Docker Compose.
9.  Реализовать разделение ответственности (Separation of Concerns) между слоями приложения (Контроллер, Сервис, Модель/Репозиторий).

### Ход работы
Данная работа является продолжением лабораторной работы №1. Необходимо модифицировать существующее приложение, добавив слой персистентности и реализовав полноценный CRUD (Create, Read, Update, Delete) через REST API с учетом требований к безопасности данных (мягкое удаление), производительности (пагинация) и управляемости схемой БД (миграции).

Изучение основ клиент-серверного взаимодействия в веб-приложениях, освоение базовых принципов работы с HTTP-протоколом, получение практических навыков создания простого веб-сервера и обработки HTTP-запросов с использованием различных технологических стеков. ### Технические требования: 
- [Java 25](https://www.oracle.com/de/java/technologies/downloads/)
- [Gradle 8.5](https://gradle.org/releases/) 
- [Docker](https://www.docker.com/products/docker-desktop/) 

### Для сбора приложения: 
#### 1. Создать и заполнить .env файл 
```bash
cp .env.example .env
```
#### 2. Собрать приложение
```bash
./gradlew bootJar
```
#### 3. Собрать образ в докере и запустить
```bash
docker compose up --build
```
