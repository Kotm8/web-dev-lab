# Лабораторная работа №5
## Тема: Кеширование данных и управление сессиями с использованием Redis

## Цель работы:
- Изучить принципы работы с системами кеширования на примере Redis.
- Реализовать механизмы кеширования для часто читаемых данных (списки ресурсов, профиль пользователя).
- Реализовать хранение идентификаторов Access токенов в Redis для возможности мгновенной инвалидации сессий.
- Освоить стратегии инвалидации кеша при изменении данных (Create, Update, Delete).
- Научиться управлять данными в Redis через CLI и интегрировать Redis в Docker-окружение с учетом безопасности.
- Закрепить модульную архитектуру приложения, добавив слой кеширования без нарушения принципов инкапсуляции.
- Обеспечить безопасность данных, хранящихся в кеше.
